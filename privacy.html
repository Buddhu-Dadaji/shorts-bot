Privacy Policy

shorts-bot is a personal tool used by a single channel owner. It requests one Google permission: youtube.upload.

Data handling

  • Uploads go directly from GitHub Actions to Google's servers.
  • OAuth credentials are stored as encrypted GitHub Actions secrets.
  • No data is sent to any third party, sold, or used for advertising.
  • No analytics or tracking cookies.

Revoking access

Access can be revoked at myaccount.google.com/permissions.
